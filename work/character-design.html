What this shows

  • Turnarounds. Each character is drawn from more than one angle (front / side, front / back) so the design holds up when it has to be built or animated.
  • A fixed palette. The finished sheet carries its own colour palette, so the character stays consistent wherever it is used.
  • Sketch → colour. Outfits are worked out as rough sketches first (Aljah’s outfit went to a V.2), then taken to a full-colour sheet.
