How I work with AI

I don’t just “use AI” — I run it like a small team with checks:

  • Work orders that quote my own instructions word for word, so the AI works from what I actually said, not from a summary.
  • An independent reviewer — a different AI from the one that wrote the work checks each output before it reaches me.
  • Repeat runs, then compare — the same task is run several times and the results compared, like checking a research instrument’s reliability.
  • Every step logged, so decisions and changes can be traced.

Design, decisions and review are mine; most code is written by AI (Claude Code, Codex, Antigravity) to my spec.
