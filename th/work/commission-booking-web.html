Commission Booking Web

เว็บรับสั่งวาดภาพสำหรับนักวาดและลูกค้า นักวาดลงแพ็กเกจของตัวเองและลูกค้าสั่งงานได้ในที่เดียว ครอบคลุมตั้งแต่สั่งงานจนลูกค้ายืนยันรับงาน

สรุปสั้น ๆ: งานในวิชา ทีม 3 คน ฉันเป็นหัวหน้าทีม ออกแบบทุกหน้าจอใน Figma และเขียนโค้ดบางส่วน สร้างเสร็จปลายปี 2025

งานในวิชา

โจทย์

งานคอมมิชชันผ่านหลายขั้นตอนระหว่างนักวาดกับลูกค้า ตั้งแต่ลงงาน สั่งงาน ตั้งราคา จ่ายเงิน ส่งงาน และยืนยัน โปรเจกต์นี้คือเว็บเดียวที่พาทั้งสองฝั่งไปครบทั้งกระบวนการ

สิ่งที่ฉันตัดสินใจ

  • ออกแบบทุกหน้าจอก่อนเริ่มสร้าง ฉันออกแบบหน้าจอทั้งหมดด้วยตัวเองใน Figma
  • สองบทบาทในเว็บเดียว นักวาดลงแพ็กเกจและผลงาน ส่วนลูกค้าเลือกดูและสั่งงาน
  • ตั้งราคาหลังสั่งงาน ลำดับคือ สั่งงาน → นักวาดตั้งราคา → จ่ายเงิน (จำลอง) → ส่งงาน → ลูกค้ายืนยัน
  • ให้นักวาดประเมินและเสนอราคาเอง งานวาดไม่เหมือนสินค้าอื่น: ราคาต้องตกลงและประเมินเป็นงาน ๆ ไป ลูกค้าบางคนมีตัวละครที่รายละเอียดเยอะ บางคนสั่งแค่ตัวละคร บางคนอยากได้ฉากหลังด้วย นักวาดจึงตั้งราคาหลังเห็นงานที่สั่ง

ผลลัพธ์

สร้างเป็นงานในวิชาช่วงปลายปี 2025 ด้วย Node.js / Express และฐานข้อมูล MySQL ตามลำดับงานข้างบน

บทบาทของฉันและการทำงานร่วมกัน

ฉันเป็นหัวหน้าทีม ออกแบบทั้งหมดใน Figma คนเดียว และเขียนโค้ดบางส่วนเอง ส่วนโค้ดที่เหลือ เพื่อนในทีมใช้ AI ช่วยเขียน
